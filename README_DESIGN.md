## 🔧 Customization

### Adjust Animation Speed
Edit `frontend/src/index.css`:
```css
--duration-normal: 250ms;  /* Change timing */
```

### Change Colors
Edit CSS custom properties:
```css
--color-primary: #1D1D1F;  /* Change color */
```

### Add New Animations
Add keyframes to `index.css`:
```css
@keyframes myAnimation {
  from { /* start */ }
  to { /* end */ }
}
```
